# Frontend

This directory is reserved for the future Next.js and TypeScript tenant-administration interface. Its boundary is configuration, status, and operational visibility through explicit authenticated backend APIs; it must never receive GitHub installation tokens, model credentials, or other server secrets.

M0 intentionally contains no Next.js project, package manifest, dependency lockfile, components, generated assets, API client, or placeholder user interface. Initialization belongs to a later milestone with explicit product and contract requirements.
